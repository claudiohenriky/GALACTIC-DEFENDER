# GALACTIC-DEFENDER — roteiro de lançamento

## v1.0.0 — versão estável

A linha principal de desenvolvimento foi consolidada na versão 1.0.0.

- [x] Combate espacial, movimentação analógica e controles para computador.
- [x] Quatro naves jogáveis: Vanguard, Phantom, Aegis e Wraith.
- [x] Habilidades de classe e progressão durante a sessão.
- [x] Hangar, personalização, missões, recompensas e conquistas.
- [x] Inimigos comuns e Elite, asteroides e chefe Encouraçado.
- [x] Cutscene de chefe, diálogos com retratos, áudio e ambiente espacial.
- [x] Ajustes de qualidade de efeitos e pós-processamento WebGL configurável.
- [x] Estado de jogo apenas em memória: sem salvamento de progresso ou preferências.
- [x] Limpeza dos dados legados do jogo identificados pelo prefixo `gd-`.
- [x] Documentação, histórico de versões e workflow de validação.
- [x] Publicação estável no GitHub Pages após aprovação dos checks.

## Pós-lançamento

A partir da v1.0.0, novas alterações devem ser tratadas como manutenção da versão estável:

- Correções de bugs confirmados.
- Ajustes de compatibilidade e acessibilidade.
- Otimizações respaldadas por medições reais.
- Melhorias visuais que não prejudiquem a legibilidade nem a taxa de quadros.

Não reabrir balanceamento de inimigos ou habilidades sem evidência de problema e revisão específica.
